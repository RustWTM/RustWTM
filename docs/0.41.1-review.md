# RustWTM 0.41.1 release scope and validation

## Scope

Patch release containing 50 evidence-audited reliability, numeric
sanitization, overflow-safety, and policy/UI hardening fixes across
`wtm-sys`, `wtm-core`, `wtm-policy`, `wtm-ipc`, `wtm-ai`, `wtm-cli`,
`wtm-service`, and `wtm-gui`. Protocol 20 is unchanged.

- **Non-finite and negative metric sanitization**: Guarded CPU, GPU,
  disk, network, I/O, sensor, and rate calculations and display
  formatting against `NaN`, `Infinity`, and negative values across
  incident frames, IPC `SystemPoint`, Telegram replies, AI tool
  summaries, CLI tables, service device series, governor/reserve/kill/
  game-mode ticks, overview, resource strip, device history, and
  container history.
- **Integer overflow and boundary safety**: Replaced unchecked `u64` /
  `u32` / `Duration` arithmetic with saturating or checked operations in
  process sampling, disk scan assembly, memory composition and map
  totals, thread CPU totals, job accounting, and startup/port/Docker
  parsing.
- **Policy, redaction, and UI correctness**: Fixed rule/insight edge
  cases, AI redaction and support-bundle handling, i18n/theme/alert
  behaviors, and service limit/history/Telegram edge cases.

## Verification

`cargo fmt --check`, `cargo clippy -j 1 --workspace --all-targets -- -D warnings`,
and the workspace test suites pass on the developer host after the
`0.41.1` version bump (`wtm-sys`, `wtm-core`, `wtm-policy`, `wtm-ipc`,
`wtm-ai`, `wtm-cli`, `wtm-service`, and `wtm-gui --lib`).
