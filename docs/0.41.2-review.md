# RustWTM 0.41.2 release scope and validation

## Scope

Patch release introducing the **System Toolkit** workspace and CLI
subcommands, Store bloatware removal, and visual consistency upgrades
across `wtm-sys`, `wtm-core`, `wtm-cli`, and `wtm-gui`. Protocol 20 is
unchanged.

- **Win32 Recycle Bin wrappers (`wtm-sys`)**: Safe `SHQueryRecycleBinW` and
  `SHEmptyRecycleBinW` bindings.
- **Core maintenance & security (`wtm-core`)**: `cleanup` (disk cleanup +
  per-process RAM trim), `risk` (contextual risk triage, Defender scan,
  quarantine), `tasks` (scheduled tasks), `tweaks` (reversible Windows
  tweaks with backup/undo), `repair` (SFC/DISM/DNS/network/restore point +
  live adapter IP/DHCP/DNS inspection), and `packages` bloatware tagging &
  Store package removal.
- **GUI (`wtm-gui`)**: Flagship `Toolkit` tab with hero banner, ring
  gauges, sparkline, stacked bars, switches, and sortable tables;
  `Overview` quick-launch card; redesigned `Installed apps` (`Desktop
  apps`, `Store apps`, `Package updates`); and shared `theme::pill` status
  badges across `Users`, `Services`, `Startup apps`, `Network`, `Ports`,
  `Containers`, and `Events`.
- **CLI (`wtm-cli`)**: `clean`, `risk`, `tasks`, `tweaks`, and `repair`
  subcommands.

## Verification

`cargo fmt --all -- --check`, `cargo clippy --locked --workspace --all-targets -- -D warnings`,
`python scripts/ci/check-locales.py`, and targeted `wtm-core`, `wtm-cli`,
and `wtm-gui` test suites pass on the developer host after the `0.41.2`
version bump.
